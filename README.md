# 像素冒险 v55 (Pixel Adventure)

一个单文件、纯前端 Canvas 实现的像素横版冒险游戏。无需安装、无需网络、无需服务器，浏览器打开即可游玩。

> 作者：张雨轩 & AI 团队
> 仅供学习娱乐，请勿商用。

## 🎮 快速开始

直接把 `code.html` 拖进任意现代浏览器（Chrome / Edge / Firefox / Safari）即可游玩，支持电脑与手机触屏自适应。

## 🕹 游戏模式

| 模式 | 说明 |
| --- | --- |
| 无尽模式 | 3 条命，四季 ⇄ 监狱主题轮换，每 250 格里程碑生命 +1 |
| 关卡模式 | 默认 51 关（含魔王关），进阶 50 城按顺序解锁 |
| 爽玩生存 | 免伤割草，精英敌人：坦克 / 直升机 / 激光守卫 |
| 自定义关卡 | 内置关卡编辑器，最高 2000 格，双指/滚轮缩放，自动保存 |

## 🧰 主要系统

- 商店 / 背包 / 金币经济（含每日口令兑换）
- 16 种武器 + 4 种载具（直升机、滑板、斗篷、坦克形态）
- 技能系统：二段跳、护盾、磁力、凤凰羽、三段跳等 30+ 技能
- BOSS 战（焰龟王）、核弹清场、直升机空投事件
- 程序化关卡生成 + 进阶 50 城主题关卡
- AI 自检：菜单内置 200 万帧机器自动通关验证

## 🕹 操作

- 电脑：方向键 / AD 移动，空格跳跃，左键开火，右键切换，Tab 背包，Q 换枪，P 暂停，T 核弹，X 下车
- 手机：左下 ◀▶ 移动，右下 ATK / JUMP，下方左右格切换武器/载具模式

## 🔧 技术说明

- 单文件 HTML，无任何外部依赖（无 CDN、无网络请求、无第三方库）
- 自研 Canvas 渲染引擎 + 程序化关卡生成（mulberry32 种子随机）
- 存档使用 localStorage（键名 `pixelquest_save_v25`），纯本地保存

## 🔒 安全与完整性

- 文件内不含任何外部 URL、`fetch`、`eval`、`XMLHttpRequest`、WebSocket 等网络或动态执行代码，完全离线自包含
- 本仓库上传后已做哈希比对核验（Git blob SHA-1），确保仓库内文件与本地原文件逐字节一致
